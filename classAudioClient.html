Detailed Description

Client-side audio control plane.

Connects to the server's audio control port, performs the DSKFAUDIO handshake and learns which UDP port to stream RTP/Opus audio to. It then starts a GstAudioSender, which captures system-output audio and streams it to the server entirely inside GStreamer.

The control socket runs on a dedicated QThread (blocking handshake, then a liveness wait) so it never assumes a Qt event loop on the core thread. The media itself flows over UDP, serviced by GStreamer's own threads.
